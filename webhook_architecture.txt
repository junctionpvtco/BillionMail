    ├─ Fetch api_templates from cache

7. API ROUTING STRUCTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Event Tracking (Public, No Auth):
  GET /pmta/{encrypted_tracking_data}
      ├─ Decrypt & validate
      ├─ Type=open → Insert mailstat_opened
      └─ Type=click → Insert mailstat_clicked, redirect

Management API (Protected with JWT):
  /api/batch_mail/
      ├─ POST /create_task
      ├─ POST /list_tasks
      ├─ POST /delete_task
      ├─ POST /task/{id}/info
      ├─ POST /task/{id}/mail_logs (event history)
      ├─ POST /task/{id}/send_count
      ├─ POST /task/{id}/stat_chart
      └─ POST /api/mail/send (API send)

  /api/abnormal_recipient/
      ├─ POST /list (bounced recipients)
      ├─ POST /add (manual add)
      ├─ POST /delete/{id}
      ├─ POST /clear (bulk clear)
      ├─ POST /switch/set (enable/disable auto-scan)
      └─ POST /switch/get (get status)

  /api/overview/
      └─ POST /stats (dashboard data)

9. ENCRYPTION DETAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Tracking URL/Pixel Encryption:
  Data: {"type": "open/click", "campaign_id": X, "recipient": "...", ...}
  ↓
  JSON Marshal
  ↓
  AES-256-CBC Encryption (PKCS7 padding)
  ↓
  Random 16-byte Key & IV generation
  ↓
  Interleave: [k0,i0,k1,i1,...k7,i7] + [k8-15,i8-15]
  ↓
  Format: IV_Key + Ciphertext + IV_Key_Tail
  ↓
  Base64 URL-safe encode (trim padding)
  ↓
  Result: {encrypted_string}

Used in:
  - Click tracking URLs
  - Pixel tracking URLs
  - Prevents spoofing/tampering
